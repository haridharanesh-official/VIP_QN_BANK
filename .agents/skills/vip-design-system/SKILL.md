# VIP Maths Commercial Design System Skill

## Purpose
Ensure every frontend feature presents a cohesive, high-end commercial SaaS aesthetic tailored for educational software.

## Brand Identity & Color Palette

- **Brand Identity**: VIP Maths — Clean, professional, trustworthy, and educational.
- **Primary Visual Palette**:
  - 🟢 **Green (Primary)**: Deep emerald/forest greens for primary actions, success states, and key highlights.
  - 🟠 **Orange (Secondary Accent)**: Warm orange for callouts, secondary actions, and highlight elements.
  - 🟣 **Magenta (Accent)**: Selective magenta for special badge indicators, tags, or focal elements.

> [!IMPORTANT]
> All color values must be referenced via CSS variables / design tokens. Do NOT re-derive custom hex values inline.

## Visual Design Principles

1. **Avoid Extreme Visual Trends**: Avoid neon cyberpunk themes, hyper glassmorphism, or crypto-dashboard aesthetics.
2. **Typography System**: Use clean, highly legible font hierarchies configured via `next/font`.
3. **Card & Table Layouts**: Use subtle borders, refined shadows, generous whitespace, and clear tabular layouts for question listings and papers.
4. **Interactive Micro-animations**: Subtle hover/focus state transitions for buttons and cards.
