# VIP Maths rebrand

User-visible product text now uses **VIP Maths** across browser metadata, authentication, navigation, dashboard, health identity, seed institution, README, and startup documentation.

The following `edugen` identifiers are intentionally retained because changing them would break compatibility or history:

- workspace package scope `@edugen/*`
- cookie names and browser storage key
- generator algorithm version
- repository directory name and historical migration names
- historical clean-room provenance statements

No QB365 branding or assets were introduced.
